# Python Port Scanner 🔐

A Python-based port scanner developed as part of my cybersecurity learning journey.

## 🚀 Features

- Scans TCP ports on a target IP address or hostname
- Identifies open ports
- Attempts to retrieve service banners
- Supports multiple targets separated by commas

## 🛠️ Technologies Used

- Python
- Socket Programming
- IPy Library

## 📋 Requirements

- Python 3
- IPy library

Install the required library:

```bash
pip install IPy
```

## ▶️ How to Run

Run the Python script:

```bash
python3 PortScanner.py
```

Enter the IP address or hostname when prompted. For multiple targets, separate them with commas.

## 🎯 Learning Objectives

- Understand TCP port scanning
- Learn Python socket programming
- Explore service banner identification
- Practice basic network security concepts
